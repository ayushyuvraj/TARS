ONE-TOUCH INSTANT START:

1. EXTRACT THIS ZIP FILE
   Extract to any local folder (e.g., C:\TARS or Desktop\TARS).

2. DOUBLE-CLICK:  START_TARS.bat  (or run.bat)
   - Automatically detects your Python 3.11+ runtime.
   - Automatically creates the isolated virtual environment (.venv).
   - Automatically installs required dependencies.
   - Zero Node.js / npm required (enterprise UI is pre-compiled).
   - Automatically launches TARS and opens your default browser at:
     👉 http://127.0.0.1:8000

   Inside "sample_data\":
   - 60,000-Row Multi-Tranche: TARS_KIGS_RECON_60000_Rows_Multi_Tranche_Scenarios.xlsx
